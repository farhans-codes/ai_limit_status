# Project instructions

## Product language

- This project is English-only.
- Keep all user-facing UI, tray, dialog, error, and notification copy in
  `lib/core/constants/app_strings.dart`.
- Do not add Flutter localization infrastructure, including `lib/l10n`, ARB
  files, `l10n.yaml`, `flutter_localizations`, or `flutter gen-l10n` steps.
- Do not add another locale unless the project owner explicitly changes this
  policy.
